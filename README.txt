BLOODLINE DISCORD WEBSITE

Files:
- index.html: complete responsive website (all CSS is included in this file).

Preview locally:
1. Download index.html.
2. Double-click it to open in your browser.

Publish for free with Cloudflare Pages:
1. Open your GitHub repository (or create a new one).
2. Replace/add the file named index.html at the repository root.
3. Commit the change.
4. If the repository is connected to Cloudflare Pages, it should deploy automatically.
